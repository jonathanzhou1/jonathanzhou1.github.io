CSCI 1710: Logic for Systems
Course Link: https://csci1710.github.io/2026/

Notable Projects:

  • Among Us Formal Modeler:

    • Among Us is a multiplayer game about crewmates doing tasks in a spaceship. There are hidden imposters among the crewmates trying to kill the crewmates. My team and I focused on modeling Among Us emergency meetings throughout the course of a game, while not modeling the game itself, in order to find interesting, unexpected gameplay dynamics such as different levels of crewmate honesty, imposters that don't kill, etc.

  • 2PC Model:

    • 2-Phase Commit is a distributed consensus protocol often used in distributed database managemeny systems to ensure atomic commits or aborts with strict data consistency. My partner and I modeled this system in Forge and replicated its successful use cases as well as the potential deadlocks.



CSCI 1660: Computer Systems Security
Course Link: https://brown-csci1660.github.io/

Term Project:

Dropbox:

Implemented an API for a secure file storage system where the Dataserver for storage is untrusted, users are untrusted as well, but there is trustworthy PKI for public key cryptography. The system allows users to create accounts, upload files, download files, share files, and revoke file access.
